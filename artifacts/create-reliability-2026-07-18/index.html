Those causes are fixed on this branch. 3D is a live deployment mismatch, not a new code path.

Browser proof

Fixed

Jingle now stops before paid media

In the real local /create screen, Generate ads created lyrics and a scene. The page kept the visible Add audio control and emitted no browser errors. No ElevenLabs request was made after the fix.

Fixed

Video Meme now returns a usable first batch

The same real browser flow created three Bear ideas without the old 60-second timeout. It made no Replicate, Seedance, image, audio, or video-generation request.

Fixed

Normal generation no longer pretends it started a Creative Pack

Generating ordinary Jingle and Video Meme scenes did not show the nine-format Creative Pack rail. The rail is now restored only after the person actually clicks Generate creative pack.

Changes made

  • Start Video Meme with at most three ideas. The bigger template set remains available for later choice/reroll; it no longer makes the first click fragile.
  • Make the Brainrot model return exactly the required JSON shape: three variants, six to ten beats each, and only left/right speakers. The existing parser still rejects bad copy.
  • Remove automatic Jingle audio calls on first generation, scene selection, and reroll. Audio is manual and visible.
  • Remember Creative Pack intent in the browser session, so ordinary format work is not mislabeled as a half-failed pack.

What was deliberately not done

  • No Replicate, Seedance, product photoshoot, image generation, or paid audio generation was called. The original live Jingle bug did make one rejected ElevenLabs request before this fix; it produced no media and exposed the bug.
  • No second renderer, model fallback, automatic retry, new provider, or hidden interaction was added.
  • No shared Convex deployment was changed from this unmerged branch. That is why 3D has a required post-merge canary instead of a risky overnight patch.
