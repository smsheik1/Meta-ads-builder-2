Browser proof

8/8 ready

The complete no-paid Creative Pack finishes

The actual customer flow on the branch generated and rendered all eight preview-safe formats for David's Cookies. The audio formats stopped at visible manual buttons.

Fixed

Jingle is creative where the model helps and deterministic where Wiggly must be exact

The model writes four small creative fields. Wiggly builds the exact hook/verse/hook timing, music style, and final brand line. This removes the fragile nested response while preserving the same output contract.

Fixed locally

Reviews uses verified proof without asking the model to retype it

The old flow rejected every card if one copied quote changed punctuation or spacing. NVIDIA now returns a constrained list of proof choices, headlines, and CTAs. Wiggly inserts its own scraped quote, so proof stays real and the model cannot accidentally corrupt it. The real local /create screen recovered all eight saved scenes with no console errors.

Fixed

Late work no longer looks like a failure

iMessage crossed the browser's 60-second deadline, then its server work completed and saved the scene. A reload found the scene and showed 8/8 ready. The new reconciliation fixes that exact confusing state in place: when the saved scene arrives, its Needs retry card becomes Ready without a second request.

Manual paid step

Product Photoshoot is honest before it spends

The real picker shows 195 products and the selected product image, then makes Generate photoshoot an explicit choice. This pass did not press it.

Pass

3D reaches five story directions before it can spend

Choosing 3D and pressing Generate ads returned five selectable David's Cookies story premises. The test stopped there, before images, video, voice, or MP4 generation.

Not launched

Motion Story cannot be mistaken for a working format

The format guide labels it Coming soon and the card is disabled.

Changes made

  • Start Video Meme with at most three ideas. The bigger template set remains available for later choice/reroll; it no longer makes the first click fragile.
  • Make the Brainrot model return exactly the required JSON shape: three variants, six to ten beats each, and only left/right speakers. The existing parser still rejects bad copy.
  • Remove automatic Jingle audio calls on first generation, scene selection, and reroll. Audio is manual and visible.
  • Remember Creative Pack intent in the browser session, so ordinary format work is not mislabeled as a half-failed pack.
  • Keep Creative Pack to eight preview-safe formats: no Motion Story, product photoshoot, or automatic audio calls.
  • When a generation saves after the browser timeout, update that one retry card from storage instead of asking the person to reload or pay for another try.
  • Constrain Reviews to exactly four model-written frames, then insert the matching verified website quote in Wiggly instead of asking the model to copy proof verbatim.
  • Reduce Jingle generation to four creative fields, then let Wiggly deterministically assemble the exact 20-second composition plan.

What was deliberately not done

  • No Replicate, Seedance, product photoshoot, image generation, or paid audio generation was called. The original live Jingle bug did make one rejected ElevenLabs request before this fix; it produced no media and exposed the bug.
  • No second renderer, model fallback, automatic retry, new provider, or hidden interaction was added.
  • No shared production deployment was changed from this unmerged reliability branch.
