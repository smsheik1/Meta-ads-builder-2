Great generative work is scattered across Instagram, X, GitHub, and creator communities. Saving the prompt is not enough: the reference images, model choice, input rules, assets, run order, and quality bar are what make the result repeatable.

Wiggly gathers the Formats worth using and turns them into **runnable content packages**. Pick one, give it to your coding agent, and make your version without rebuilding the workflow from scratch.

## Try a Format in 60 seconds

1. **[Browse the live catalog](https://wiggly.agentenamel.com/discover)** and choose a finished result you want to make.
2. Open the Format to see its real examples, source attribution, exact prompt, model routes, and production rules.
3. Download the runnable kit and give it to Claude, Codex, or another coding agent with your input.

For example:

```text
Open https://wiggly.agentenamel.com/format-lab/fortnite-filter
and use its runnable kit to turn my attached portrait into this Format.
Follow the included checks and show me the inspected final image.
```

Today Wiggly is bring-your-own-agent and bring-your-own-key. Paid model calls require your approval; every compatible Repo can validate and estimate before it spends.

## What makes a Format runnable?

A prompt tells a model what to make. A **Wiggly Repo** tells an agent how to finish the job.

| Inside each Repo | What it does |
| --- | --- |
| Prompt and references | Preserve the creative idea and make the target visible. |
| Input contract | Define what the user supplies and what can change. |
| Model routes | Offer economy, default, and premium paths when available. |
| Runner and assets | Turn the recipe into a repeatable production workflow. |
| Validation and approval gates | Catch broken inputs and prevent surprise paid calls. |
| Goldens and visual checks | Prove what good looks like before a result is finalized. |

The creative changes; the production knowledge stays reusable. Cartoon Explainer keeps its layouts, pacing, renderer, and checks while the characters and lesson change. 3D Breakdown keeps its planning and review loop while the brand, product, narration, and shots change.

That is the GitHub idea applied to generative media: make a good Format once, then let the next person run it, remix it, and improve it.

## Run Wiggly locally

```bash
npm install
npm run dev
```

The v3 app starts at [`http://localhost:3020/create`](http://localhost:3020/create). See [Development](docs/development.md) for environment setup, architecture, runtime checks, and deployment notes.

## Help shape the registry

Wiggly is an active public beta. If there is a creative workflow the world should be able to run, [request a Format](https://github.com/smsheik1/wiggly/issues/new). If you improve an existing Repo, open a pull request so the next person starts with the better version.
