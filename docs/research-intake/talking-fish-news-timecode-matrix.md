# Talking Fish News: Timecode Matrix

## How To Read This

This is an observation log, not a production script library. Times are rounded from the
public mirror and captions are only used where the channel exposed auto-captions. The point
is to test structure, not to reproduce a report word-for-word.

## Cross-Episode Findings

1. **The anchor does not earn screen time by moving.** It is a repeated authority marker;
   the upper evidence moves as the report advances.
2. **Every structural beat has a visible proof change.** A longer runtime only works when
   the evidence changes again; it does not justify more product explanation.
3. **Closing language is optional.** A proof, a consequence, a developing-story cue, or a
   follow line can close. The source does not establish a station sign-off as required.
4. **The report starts before the viewer has context.** `Breaking news` plus a concrete
   event is the context; it is not an intro to the format.

## Design Consequence

A Wiggly episode must plan a proof image before it earns a line of narration. If an agent
cannot name the large phone-readable proof for a line, it has not written a report yet.
