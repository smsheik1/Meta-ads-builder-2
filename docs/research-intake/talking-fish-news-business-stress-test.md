# Talking Fish News: Four-Business Stress Test

## Rule

These are desk simulations, not published ads. A card is allowed to pass only when its
claim is supported by the cited official page and the evidence can be shown large on a phone.
No paid model or media call was used.

## Ecommerce: FinalStraw

Official evidence: [product page](https://finalstraw.com/products/finalstraw) and
[brand home page](https://finalstraw.com/).

| Lane | News event | Proof sequence | Verdict |
| --- | --- | --- | --- |
| Hidden cost | The disposable straw is the part people keep forgetting to replace. | Used plastic straw pile; FinalStraw collapsed; case on a keychain. | Pass |
| Category change | A full-length drinking straw now folds into its own case. | Closed case; straw opening; full straw beside a drink. | Pass |
| Evidence alert | A reusable straw can live in the same place as a car key. | Keyring/case; straw extension; drink use. | Pass |
| Customer incident | Forgetting a straw no longer requires buying another disposable one. | Empty bag pocket; case clipped to keyring; straw in drink. | Conditional: needs a real customer quote or a neutral rewrite. |
| Origin report | One collapsible straw started a wider reusable-gear line. | Original product; product range; brand history proof. | Conditional: needs official dated origin imagery. |

**Selected report:** Category change.

> Breaking news. A full-length drinking straw can now fold into a case small enough for a
> keychain. FinalStraw opens to normal length, then collapses back into its recycled-plastic
> case. The point is not a new straw. It is never needing the disposable one again.

Visual plan: closed case in hand -> telescoping product opening -> full straw in an iced drink
-> used plastic straw contrast -> product and case together. The brand enters on the second
proof image, after the event is clear.

## SaaS: Recall.ai

Official evidence: [Recall home page](https://www.recall.ai/) and
[Meeting Bot API documentation](https://docs.recall.ai/docs/quickstart).

| Lane | News event | Proof sequence | Verdict |
| --- | --- | --- | --- |
| Hidden cost | A meeting can end before its information reaches the product that needs it. | Meeting grid; recording/transcript/media icons; API handoff diagram. | Pass |
| Category change | One API can return the recording, transcript, and meeting metadata. | Meeting input; three large output artifacts; simple API flow. | Pass |
| Evidence alert | A meeting bot can join a call and return a recording after the meeting ends. | Calendar/meeting link; bot join state; recording-ready state. | Pass |
| Customer incident | A product team lost a customer call until Recall recovered it. | N/A | Fail: no supported case evidence selected. |
| Origin report | Recall built a unified meeting-data layer because every platform was different. | N/A | Fail: no sourced history proof selected. |

**Selected report:** Category change.

> Breaking news. A single meeting can now leave behind more than a calendar event. Recall's
> API can return the recording, transcript, and meeting metadata from a captured call. For
> teams building meeting products, the call is no longer a dead end. It is usable data.

Visual plan: recognizable meeting grid -> three oversize artifact cards: recording,
transcript, metadata -> one clean API-arrow diagram -> branded API result card. No dense
dashboard screenshot and no invented customer statistic.

## Local Service / Franchise: Orangetheory Fitness

Official evidence: [heart-rate zone explainer](https://www.orangetheory.com/en-us/articles/understanding-heart-rate-zones-and-how-they-help-boost-your-fitness)
and [workout page](https://www.orangetheory.com/en-us/workout?947f74f7_page=3&d2101103_page=3).

| Lane | News event | Proof sequence | Verdict |
| --- | --- | --- | --- |
| Hidden cost | Feeling exhausted does not tell a member which effort zone they trained in. | Runner; heart-rate colors; large zone display. | Pass |
| Category change | A group workout can show each member's effort in real time. | Class floor; wearable; OTconnect zone screen. | Pass |
| Evidence alert | Orangetheory uses five heart-rate zones, including an Orange Zone range. | Five-zone graphic; wearable; coach/class image. | Pass, avoid outcome promises. |
| Customer incident | A member finally hit exactly twelve Splat Points. | N/A | Fail: individual result requires direct proof. |
| Origin report | The original studio invented a new cardio method. | N/A | Fail: history proof not selected. |

**Selected report:** Category change.

> Breaking news. A room full of people can train at different intensities without doing
> different workouts. Orangetheory's display maps each member into five heart-rate zones in
> real time. The number is not the workout. It is the signal that tells each person when to
> push or recover.

Visual plan: wide class showing different people -> a single large wearable/zone display ->
five-color zone diagram -> coach pointing to the shared display -> studio proof. The report
does not promise health outcomes.

## Information Business: Maven

Official evidence: [Maven course overview](https://maven.com/maven/course-bootcamp) and
[Maven Course Accelerator](https://maven.com/maven/course-accelerator).

| Lane | News event | Proof sequence | Verdict |
| --- | --- | --- | --- |
| Hidden cost | A course can end with watched videos and no work shipped. | Passive video player; live workshop; project board. | Pass |
| Category change | A cohort course combines workshops, videos, articles, and projects. | Four large mode icons; live class; project artifact. | Pass |
| Evidence alert | Cohort learning adds collaboration to normal course material. | Group workshop; course content; peer workspace. | Pass |
| Customer incident | A creator launched a course in under three weeks. | N/A | Fail unless the selected instructor page is cited. |
| Origin report | Maven coined cohort-based learning. | Conditional: its marketing uses that language, but a public release needs a precise source and careful attribution. |

**Selected report:** Hidden cost.

> Breaking news. Watching a course is not the same as finishing the work inside it. Maven's
> cohort courses pair live workshops, course material, and projects in one run. The lesson is
> not another tab to leave open. It is work with a deadline and other people in the room.

Visual plan: paused course video -> live workshop grid -> project board -> schedule with a
single deadline -> course page proof. The evidence is familiar and legible without reading a
small webpage.

## Result

All four categories produce at least one reportable event, but only when the desk rejects
unsupported origin stories, customer outcomes, and broad performance claims. The format is
therefore viable across the four types without pretending every brand has a breaking-news
story.
