# Talking Fish News: Asset Inventory

## Research Assets: Private Only

- Source URLs, timing notes, and frame observations.
- No source video, voice, logo, character art, music, or station graphic is checked into this
  repository or used in a public Wiggly output.

## Required Original Production Assets

| Asset | Use | Source requirement |
| --- | --- | --- |
| Recurring fish anchor | Lower-panel continuity marker | New original character and poses. |
| Underwater news backing | Simple anchor backdrop | New original 2D background. |
| Generic report header | Recognizable wrapper | New original typography and layout. |
| Caption system | Spoken-line reinforcement | Renderer overlay, never generated into pixels. |
| Evidence panel | The actual story | Official brand assets, product images, supported screenshots, or created diagrams. |
| Voice | Neutral report delivery | BYOK voice provider or user audio; no private TTS dependency. |
| Final action overlay | Optional destination | Renderer overlay with a supported URL or action. |

## Evidence Asset Rules

- Use the brand's real product, interface, location, founder/history, or proof whenever it
  exists.
- A screenshot is allowed only when the essential detail is readable at phone size.
- If an interface is too dense, extract one real, high-signal state or create an original
  explanatory diagram grounded in that state.
- Do not invent a dashboard, news article, scientific test, customer result, or product
  packaging.
