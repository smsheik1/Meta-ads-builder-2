# Talking Fish News: Wiggly Proof Pre-Production

## Scope

Build one original 14-20 second Wiggly mini-report. This is a proof of the
format, not a `/create` integration, Discover entry, or portable kit.

## Selected Report

### Objective

Show the category change: Wiggly turns a creative recipe into something an
agent can carry to the next brand.

### Script

**Word count: 53. Target voice duration: 18.4 seconds.**

1. `Breaking news. One creative recipe can now make ads for entirely new brands.`
2. `A prompt can ask AI for one result, then disappear.`
3. `Wiggly keeps rules, examples, and quality checks together so an agent can carry creative judgment into the next brand.`
4. `The output is not one ad; it is a repeatable format.`

### Proof Plan

| Time | Spoken line | Top-panel proof | Caption | Visible change |

## Original Fixed Assets

The report wrapper must be original and generic:

- One illustrated fish anchor in the lower panel, calm and nearly static.
- Deep teal underwater gradient and soft caustic light, rendered locally.
- `THE DAILY CURRENT` header and a generic `REPORT` tag.
- Captions and final `wiggly.agentenamel.com` overlay rendered by the renderer.
- No source character, station name, station art, audio, or voice.

## Fixed Anchor Asset

The user supplied the fish anchor image directly. It is stored as
`/talking-fish-news-assets/fixed-fish-anchor.png` and remains fixed across the
entire proof.

- No image-generation call.
- No video-generation call.
- The renderer supplies the original Wiggly desk, underwater report wrapper,
  captions, and station treatment around the fixed anchor.
- A supplied blue underwater flower pattern is used only as a low-opacity studio
  texture behind the desk.
- The fish is a quiet continuity device. It never lip-syncs, narrates, or
  competes with the evidence panel.

## Local Proof Gate

Build the 14-20 second MP4 locally through the existing `AdRenderSurface` and
Remotion path. This proof has no paid provider call.
