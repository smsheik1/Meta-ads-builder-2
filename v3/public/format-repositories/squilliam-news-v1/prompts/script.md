# Squilliam News script procedure

Write one continuous 30-second bulletin of 65–112 words.

Required beats:

1. Squilliam identifies himself and declares the promotion an emergency.
2. State the central value in concrete language.
3. Include one short Squidward jab only.
4. Deliver the date, time, age restriction, and location when applicable.
5. Give one explicit CTA.
6. End with a character-specific sign-off.

The joke may frame the promotion, but the promotion remains the story. Do not invent event facts, prices, performers, availability, or urgency. Add pronunciation overrides for unusual names before voice generation.
