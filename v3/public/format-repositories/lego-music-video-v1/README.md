# Lego Music Video

A brand ad in a Lego music-video world—not the audio-only Brand Jingle Repo.

The downloadable kit contains the official runtime, contracts and two recovered David's Cookies examples. Your coding agent handles research and storytelling. Optional music and image/video providers supply only approved media.

Read **SKILL.md** for the one operating workflow. From the archive root, read **KIT-MANIFEST.json** for the exact version and inventory; all commands run in **v3**.

Local inputs and completed media are under `public/format-repositories/lego-music-video-v1/agent-runs/<run>`. The two goldens include their source media, new local exports, checks and provenance. Both passed technical checks. Their direct audiovisual creative review is **unreviewed**, not passed.

No new paid generations were used to build or test this package. Current optional providers have request-contract tests, not a fresh paid end-to-end certification. Node/npm and a Chrome download need network access during setup; supplied-media rendering needs no generation service.
