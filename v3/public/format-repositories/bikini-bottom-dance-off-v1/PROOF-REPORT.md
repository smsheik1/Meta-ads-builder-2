# Bikini Bottom Dance Off Wiggly Repo proof

Format version: `0.8.0`

## Boundary decision

- Package the official character renderer, retargeter, four verified motion profiles, composition runtime, quality inspector, local motion importer, and non-secret voice presets.
- Treat the song, outer-canvas background, script, colors, roster order, and every solo/finale/reaction motion assignment as episode inputs.
- Make Fish Audio the only runtime provider call, and only when a required dialogue cache entry is missing or stale after validation and explicit approval.
- Treat Mixamo as an operator-time source for a local Collada import, not a runtime API. Do not package or execute browser-token bulk downloaders.

The machine-readable version of this decision is `content-boundary.json`.

## Failures and fixes

- The Format originally depended on a sibling motion Repo that existed only in the source tree. The ZIP now ships both official Repos as one npm workspace, preserving one renderer while making the artifact runnable after clean extraction.
- The body-language motion was hardcoded as `taunt`. Every character now supplies `reactionMotionId` alongside its solo and finale IDs.
- The first sandboxed smoke attempt could not open the local loopback renderer. The same command passed with loopback permission; this was an execution-environment restriction, not a provider or Format failure.
- The first packaged check exercised only the Dance Off workspace. It now runs the bundled motion foundation's tests too, including a disposable real import, so the ZIP proves both halves of the system.
- The first Dance Off clips baked in the motion lab's generic teal gradient, then temporarily used the dark Squilliam newsroom. The compositor now requests the separate `fish-news` preset and keys cached clips by it, so all four performers share the exact bright flower-and-bubble Fish News background without changing Squilliam News.
- The saturated Fish News art made the old RGB replay-seam SSIM report a false failure even though the start and end frames were visually identical. The compositor now forces a keyframe at the replay bridge and the inspector measures luma SSIM at the unchanged 0.995 threshold; the rendered smoke proof scored 0.996239.
- The first outer canvas was a hard-coded navy fill. Four user-approved concept directions now ship as normalized 1080x1920 plates selected through `outerBackground`; their IDs, hashes, and source note live in one packaged manifest, and the renderer still owns every character pixel.
- The detailed dance-club caustics made two visually matching replay frames score 0.993305 at full resolution because H.264 quantized fine texture differently at opposite ends of the file. Comparing the preserved frames at half-scale luma kept the strict 0.995 gate and measured the visible structure at 0.996416.
