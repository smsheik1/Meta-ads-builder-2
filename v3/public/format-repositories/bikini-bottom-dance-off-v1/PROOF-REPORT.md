# Bikini Bottom Dance Off Wiggly Repo proof

Format version: `0.7.0`

## Boundary decision

- Package the official character renderer, retargeter, four verified motion profiles, composition runtime, quality inspector, local motion importer, and non-secret voice presets.
- Treat the song, script, colors, roster order, and every solo/finale/reaction motion assignment as episode inputs.
- Make Fish Audio the only runtime provider call, and only when a required dialogue cache entry is missing or stale after validation and explicit approval.
- Treat Mixamo as an operator-time source for a local Collada import, not a runtime API. Do not package or execute browser-token bulk downloaders.

The machine-readable version of this decision is `content-boundary.json`.

## Proof inputs

1. `fixtures/smoke/input.json`: the original Wiggle choreography used in the first complete Reel.
2. `fixtures/alternate/input.json`: different solo and finale motions for all four characters, two different reaction assignments, different colors, and a different proof title.

The alternate real run reused the original local song and accepted voice cache. Validation reported twelve explicit motion assignments, `mixamoApiCalls: 0`, `fishAudioCallsRequired: 0`, and `fishAudioApprovalRequired: false`.

## Failures and fixes

- The Format originally depended on a sibling motion Repo that existed only in the source tree. The ZIP now ships both official Repos as one npm workspace, preserving one renderer while making the artifact runnable after clean extraction.
- The body-language motion was hardcoded as `taunt`. Every character now supplies `reactionMotionId` alongside its solo and finale IDs.
- The first sandboxed smoke attempt could not open the local loopback renderer. The same command passed with loopback permission; this was an execution-environment restriction, not a provider or Format failure.
- The first packaged check exercised only the Dance Off workspace. It now runs the bundled motion foundation's tests too, including a disposable real import, so the ZIP proves both halves of the system.

## Completion audit

- **Reusable and runnable:** the downloadable npm workspace contains both official Repos, installs cleanly, and renders offline.
- **Different dances per episode:** all twelve motion assignments are input fields; the alternate fixture replaces every solo and finale without runtime changes.
