## Post-action retro

**What did this teach us, and does the skill, runtime, or test suite need updating?**

- Durable semantic rule: timing and facial expression do not define an action by themselves. A celebration needs celebration-specific silhouette vocabulary; an open-palm shrug cannot be relabeled merely because the mouth smiles.
- Durable substitution rule: for a bilateral gesture whose recovered drawing family contains only one valid semantic hand, a deterministic mirror of that exact registered drawing is acceptable when anatomy is symmetric, the transform is disclosed, and the original and derived bytes are test-locked. The mirror must replace only the missing counterpart, not become generic new art.
- Runtime update: none. The ordinary registered-prop path and local aspect support already expressed the action.
- Inspection/test update: a dedicated victory-fist composite gate requires the exact two front substitutions while preserving both finished sleeves; tests prove source-byte identity, deterministic horizontal mirroring, contact timing, source-control retention, and exact generator reproducibility.
