# Script Prompt

The official runner writes the exact selected-concept prompt with:

```bash
npm run format:talking-fish-news -- script-prompt --run <run-id>
```

The prompt locks four beats to the approved story moves: a self-contained beginning, escalation that creates a question, reveal that answers it, and a resolved ending with the approved deadpan punchline. It applies a removal test: if beat two or three can disappear without breaking the logic, the script fails. It requires 38-60 words, source-grounded facts, plain spoken language, and no sales pitch, fact-stacking, or invented claim.
