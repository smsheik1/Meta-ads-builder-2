# Apology prompt

Run:

```bash
npm run format:were-sorry -- prompt --run=<id>
```

The command writes `were-sorry-prompt.txt` from the exact production prompt in `features/formats/were-sorry/prompt.ts`.

Use that prompt without adding a new style or structure. Return plain JSON and save it as `variants.json`.

The legal wrapper must stay serious. Every confession must be a different supported product benefit or buyer moment reframed as fake harm.

Each variant must include `evidenceRefs`: one or more exact strings copied from `research.json`. The validator rejects missing or invented citations, unsupported numbers, timeframes, guarantees, and absolute claims.
